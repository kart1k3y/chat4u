# MINI PROJECT #06: Automated Artifact Versioning Pipeline
**[Best done on: Day 3]**

## Project Brief
Create a GitHub Actions pipeline that automatically builds a Docker image, tags it with the git commit SHA and semantic version, pushes to Docker Hub, and creates a GitHub Release with changelog.

## Skills Applied
- GitHub Actions
- Docker
- Semantic Versioning
- Release Automation

## Success Outcome
Every git tag creates a versioned, deployable release automatically
