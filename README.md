# MINI PROJECT #08: Kubernetes Horizontal Pod Autoscaler

**Project Brief:** 
Deploy a CPU-intensive app to Kubernetes. Configure HPA to scale from 2 to 8 pods based on CPU usage. Use the `hey` load testing tool to generate traffic and capture a screen recording of pods scaling up and down.

**Skills Applied:** 
- Kubernetes
- Horizontal Pod Autoscaler (HPA)
- Load Testing
- Metrics Server

**Success Outcome:** 
Demonstrated auto-scaling under load — a core DevOps capability.

**Note:** A video recording (`pods_scaling_Video.mp4`) demonstrating the pods scaling up and down in real-time has been added to this repository!
