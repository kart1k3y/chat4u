# Chat4U

Chat4U is a web-based chat application currently under development.

## About

This project aims to provide a simple and modern chat platform built with Flask. The application is in its early stages, and features will be added incrementally as development progresses.

## Tech Stack

* Python
* Flask
* HTML/CSS
* JavaScript

## Getting Started

### Prerequisites

* Python 3.12+
* Git

### Installation

```bash
git clone https://github.com/your-username/chat4u.git
cd chat4u
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate it:

**Linux/macOS**

```bash
source venv/bin/activate
```

**Windows**

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```
